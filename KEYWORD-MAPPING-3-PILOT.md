# KEYWORD MAPPING — 3 PILOT CITY LOCAL SEO

Tanggal: 2026-09-18

Dokumen ini menjadi peta keyword kerja untuk tiga pilot city Nakama Digital:
- Luwuk
- Sintang
- Surabaya

Tujuan utama bukan memasukkan seluruh keyword ke satu halaman, tetapi memetakan keyword berdasarkan search intent dan menentukan kapan keyword cukup ditangkap halaman kota atau membutuhkan halaman layanan terpisah.

- /surabaya/

Tier 2 ditangkap secara natural melalui heading, deskripsi layanan, FAQ, CTA, dan paragraf kontekstual. Tidak perlu membuat satu halaman untuk setiap variasi.

### Tier 3 — kandidat halaman layanan
Keyword yang mempunyai intent layanan yang cukup berbeda sehingga dapat menjadi halaman terpisah setelah ada data Search Console atau demand yang mendukung.

Kandidat:
- company profile website [kota]
- jasa pembuatan toko online [kota]
- landing page design [kota]
- jasa website UMKM [kota]
- jasa website sekolah [kota]
- jasa redesign website [kota]

- jasa SEO website [kota]

Aturan: jangan membuat halaman Tier 3 hanya karena keyword tersedia. Prioritas ditentukan dari query nyata, impressions, relevansi bisnis, dan kebutuhan konten unik.

Kata seperti "termurah", "terbaik", atau "no 1" tidak boleh dijadikan klaim faktual tanpa bukti yang dapat dipertanggungjawabkan.

## 7. Cannibalization rule

Jangan membuat dua halaman yang menarget intent hampir sama.

Contoh yang TIDAK dilakukan tanpa alasan:
- /luwuk/
- /jasa-website-luwuk/
- /pembuatan-website-luwuk/

Jika intent sama, satu halaman kuat lebih baik daripada beberapa halaman tipis.

## 8. Trigger pembuatan halaman baru

Halaman layanan baru dipertimbangkan bila minimal ada:
- query nyata yang konsisten di Search Console;
- intent berbeda dari halaman kota;
- konten unik yang cukup untuk menjawab intent;
- internal-link destination yang jelas;
- manfaat bisnis yang masuk akal.

## 9. Next measurement

Setelah tiga pilot terindeks dan memperoleh data:
- export query Search Console;
- kelompokkan query berdasarkan cluster;
- bandingkan query dengan keyword mapping ini;
- cari keyword yang mendapat impressions tetapi belum memiliki coverage kuat;
- optimalkan existing page terlebih dahulu;
- baru buat halaman Tier 3 yang benar-benar diperlukan.

## 10. Prinsip utama

3 pilot city tetap menjadi ruang eksperimen.

Tidak ada ekspansi kota baru sampai:
- struktur teknis stabil;
- indexing dapat dipantau;
- query organik nyata sudah terkumpul;
- keyword overlap/cannibalization sudah diperiksa;
- kebutuhan halaman layanan tambahan sudah terbukti.
